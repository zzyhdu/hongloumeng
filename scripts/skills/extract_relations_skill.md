# 红楼梦人物关系逐章提取 (Chapter Extract Skill)

## 技能描述
利用 Antigravity 大模型的理解能力，逐章阅读《红楼梦》本地 JSON 文件，提取**所有出场人物**的关系。每章结果独立保存到 `resource/llm_chapters/` 目录，支持断点续传。

## 执行指令
当用户下达指令（例如："运行提取技能，处理第 1 回到第 10 回"）时，请执行以下工作流：

### 1. 初始化
- 创建 `resource/llm_chapters/` 目录（如不存在）
- 检查该目录下已有哪些章节结果文件（如 `001.json`），已有的**跳过**（断点续传）

### 2. 逐章处理（核心循环）
对于用户指定范围内的每一回（如 001, 002, ...）：
- 使用 `view_file` 读取 `resource/rm120/[回目编号].json`
- 从 blocks 中提取所有 paragraph 和 poetry 的纯文本
- 分析文本，提取**所有出场人物之间的关系**
- 将结果保存到 `resource/llm_chapters/[回目编号].json`

### 3. 合并与汇报
- 处理完所有回目后，运行合并命令：`.venv/bin/python scripts/llm_extract_relations.py --merge-only`
- 向用户汇报处理结果

## 提取规则
1. **不限人物范围**：识别文本中所有出场的人物，包括次要角色（如小厮、丫鬟、和尚道士等）
2. **统一人名**：将别名/称呼统一为最常见的全名（如"宝二爷"→"贾宝玉"，"凤姐"→"王熙凤"，"老太太"→"贾母"，"蘅芜君"→"薛宝钗"）
3. **基于文本**：只提取本章文本中**明确提到或可直接推断**的关系，严禁用预训练知识脑补文中未提及的关系
4. **关系分类**：type 字段取值为 亲属/夫妻/主仆/朋友/师徒/情感/对立/其他

## 输出格式
每章保存为 JSON 数组，每个元素：
```json
{"source": "人名A", "target": "人名B", "relation": "关系描述", "type": "类别", "chapter": "003"}
```
