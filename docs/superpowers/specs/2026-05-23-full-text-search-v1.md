# Full Text Search V1

## 概述

全文搜索 V1 面向已完成的小说阅读功能，目标是在不引入后端服务的前提下，让读者可以按关键词检索当前版本的章回文本，并从搜索结果直接跳转到原文位置。

本版本优先保证稳定、可跳转、可高亮。语义搜索、拼音搜索、跨版本对照搜索不纳入 V1。

## 搜索范围

- 默认只搜索当前选中的版本，不跨版本混搜。
- 默认搜索范围包括：
  - 章回标题
  - 正文段落
  - 诗词
- 批注和脚注作为可选范围：
  - 默认不纳入搜索结果
  - 搜索面板提供“包含批注/脚注”开关

## 入口与布局

- 顶部 Header 增加搜索按钮。
- 点击搜索按钮后打开独立搜索面板。
- 桌面端和移动端共用同一套搜索面板。
- 现有侧边栏的目录搜索保留，仅用于过滤章回标题，不承担全文搜索。

搜索面板包含：

- 搜索输入框
- 当前搜索版本提示
- “包含批注/脚注”开关
- 结果列表
- 空状态、加载状态、错误状态

## 搜索规则

- 支持中文关键词精确匹配，例如“黛玉”“葬花”“风月宝鉴”。
- 支持空格分隔多关键词，例如“宝玉 黛玉”。
- 多关键词使用“同时包含”规则，只有同一条索引文本同时包含所有关键词才算命中。
- 英文大小写不敏感。
- V1 不支持：
  - 语义搜索
  - 拼音搜索
  - 正则搜索
  - 模糊匹配

## 搜索结果

每条结果显示：

- 所在章回标题
- 内容类型：标题 / 正文 / 诗词 / 批注 / 脚注
- 命中片段
- 关键词高亮

排序规则：

- 按章回顺序排列。
- 同一章内按原文 block 顺序排列。
- 单次最多展示前 200 条结果，避免列表过长。

## 点击结果

点击某条结果后：

- 切换到对应章回。
- 自动滚动到命中的段落、诗句或注释。
- 在正文中高亮当前命中位置。
- 如果当前已经在目标章回，直接滚动到命中位置。

## 静态索引

不在运行时一次性 fetch 所有章节 JSON。构建阶段生成静态搜索索引：

```
resource/search-index/{versionId}.json
```

建议在目录生成流程中同步生成索引，保证 `npm run dev` 和 `npm run build` 都能拿到最新索引。

索引条目建议字段：

| 字段 | 说明 |
|------|------|
| `versionId` | 版本 ID |
| `chapterId` | 章回 ID |
| `chapterTitle` | 章回标题 |
| `chapterOrder` | 章回顺序 |
| `blockIndex` | 原章节 JSON 中的 block 下标 |
| `blockType` | 原始 block 类型 |
| `scope` | 搜索范围分类：title / body / poetry / annotation / footnote |
| `text` | 可搜索文本 |

前端根据 `versionId` 加载对应索引。切换版本后，搜索面板只使用新版本索引。

## 原文定位

为支持跳转和高亮，阅读渲染层需要能根据搜索命中信息定位到具体 block：

- `ChapterRenderer` 渲染每个 block 时暴露稳定 DOM 标识。
- 标识至少包含 `chapterId` 和 `blockIndex`。
- 搜索结果跳转时传入目标 `chapterId`、`blockIndex` 和关键词。
- 章节加载完成后滚动到目标 block，并给该 block 添加临时高亮。

## 验收标准

- 搜索“黛玉”能返回当前版本内的跨章回结果。
- 搜索“葬花”能跳到对应章节附近并高亮命中位置。
- 搜索“宝玉 黛玉”只返回同时包含两个关键词的条目。
- 切换版本后搜索只查当前版本。
- 不勾选“包含批注/脚注”时，批注和脚注里的命中不出现在结果里。
- 现有目录搜索仍然只过滤章回标题。
- `npm run build` 通过。

## 后续扩展

V1 完成后可考虑：

- 跨版本搜索与版本对照。
- 人物别名归一，例如“凤姐”“王熙凤”。
- 拼音搜索。
- 语义问答或语义检索。
- 搜索历史和常用关键词。
